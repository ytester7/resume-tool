# resume-tool 伴随进程（mcp-server）

本地运行的 Boss直聘 **只读** 抓取助手：把岗位 JD 从「岗位链接」一键带进简历工具的投递台账，
并把 `search_jobs` / `fetch_jd` / `open_login_browser` 三个工具以 MCP 协议暴露给
Claude Desktop、Cursor 等外部 Agent。

## 数据红线（重要）

本进程产生的**一切可写数据都收敛在仓库根目录的 `.mcp/` 下**，绝不写入用户主目录、
AppData 或系统临时目录；`.mcp/` 已被 .gitignore 排除，永远不会进入仓库：

```
.mcp/
├── browser-profile/   # Chromium 用户数据（登录态 / Cookie）
├── browsers/          # Playwright 浏览器二进制（安装时也指向这里）
└── logs/              # 按天滚动的运行日志
```

其他人克隆本仓库使用时，数据同样落在**他们的项目目录**里；删除 `.mcp/` 即彻底清空
登录态与全部痕迹。

## 使用步骤

```bash
# 1. 安装依赖与浏览器（都进项目内，不污染全局）
npm run mcp:install

# 2. 启动伴随进程（http://127.0.0.1:41722，仅本机回环）
npm run mcp

# 3. 首次使用先扫码登录（另开一个终端）
npm run mcp:login
```

然后在简历工具里：工具栏公文包 → 记录一个岗位 → 粘贴 Boss直聘岗位链接 →
「从链接抓取 JD」。状态徽标显示「Boss直聘直连 · 在线」即已连通。

## 安全设计

- **只读红线**：只有「读」（搜索、抓 JD），没有任何投递、打招呼、发消息能力，代码层面就不存在这些接口
- **风控即停**：探测到验证码 / 安全页 / 登录墙立即终止当前操作并提示，**绝不自动重试、绝不绕过**
- **限速**：对 zhipin.com 的每次导航间隔 9–15 秒随机抖动，单会话上限 60 次请求
- **域名白名单**：只允许访问 `https://www.zhipin.com`，其他任何 URL 一律拒绝
- **仅回环监听 + 来源校验**：HTTP API 只绑定 127.0.0.1，且只接受本机开发地址
  （localhost / 127.0.0.1 任意端口）或 `file://` 页面的请求——任意外部网页无法借你的登录态调用本进程；
  不要把端口转发到公网或局域网
- **浏览器可见**：抓取使用可见浏览器窗口（最小化在任务栏），用户随时能看到它在做什么

## 风险声明

Boss直聘没有官方开放 API，本进程基于浏览器自动化读取**你自己登录后可见的页面**。
自动化访问可能违反平台用户协议，极端情况下存在账号限制风险。本进程已通过
只读、限速、遇风控即停等手段把风险压到最低，但请知悉：

1. 仅供个人求职用途，请合理控制使用频率；
2. 由此产生的账号风险由使用者自行承担；
3. 请勿修改本代码添加自动投递等写入类能力。

## MCP 接入（可选）

外部 Agent（Claude Desktop 等）通过 **stdio 模式**使用工具。在客户端配置中添加
（注意 `--stdio` 参数；该模式下进程只走 stdin/stdout 的 JSON-RPC，不启动 HTTP 服务）：

```json
{
  "mcpServers": {
    "resume-tool-boss": {
      "command": "node",
      "args": ["<本仓库绝对路径>/mcp-server/src/server.js", "--stdio"]
    }
  }
}
```

工具清单：`search_jobs(query, city?, page?)`、`fetch_jd(url)`、`open_login_browser()`。

## 开发

```bash
npm run mcp:test   # 纯函数单测（路径收敛 / 限速 / 风控探测 / 页面解析）
```

Boss直聘页面结构会变化；解析失败时会返回明确的 `PARSE_EMPTY` 错误而不是猜测数据，
届时需要更新 `src/extract.js` 中的选择器。
